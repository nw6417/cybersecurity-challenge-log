Challenge Log: Inspect HTML
Date: 10/8/26

Category: Web Exploitation
 
What I did: I pressed Ctrl+U to inspect the webpage's HTML source code.

My reasoning: I knew the flag might be hidden in the page's source so I looked through the HTML for it.

What I found: A flag was included in the public HTML source.

What I learned: Information in a webpage's source code can be viewed by anyone who inspects the page.

Security lesson: Never put sensitive information in public facing source code.
