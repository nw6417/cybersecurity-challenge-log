# POST-COMPLETION

## Summary
I completed **15+ cybersecurity challenges** across multiple categories, including picoCTF and OverTheWire Bandit. I learned how vulnerabilities work, how information can be exposed, and how to recognize and prevent security risks.

## Challenges

- **Inspect HTML** – Found information exposed in webpage source code.
- **Log Hunt** – Found flag pieces in server logs.
- **Mod 26** – Decoded a message using ROT13.
- **Bandit** – Practiced Linux commands, file searching, and reading files.
- **Other picoCTF challenges** – Practiced cryptography, forensics, web exploitation, and general cybersecurity skills.

## Security Risks

- Public webpage code can expose sensitive information.
- Server logs can accidentally reveal private data.
- ROT13 is easy to reverse and should not be used for security.
- Weak security practices can allow vulnerabilities to expose information.

## What I Learned

- How to use Linux command-line tools.
- How to recognize common security vulnerabilities.
- How to inspect files, metadata, webpage code, and logs.
- How to use AI for hints and explanations while checking its answers myself.

## Final Goals

- Build a stronger understanding of cybersecurity.
- Recognize security risks and how to prevent them.
