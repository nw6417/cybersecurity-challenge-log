# Incident Response Runbook

# 1. Preparation
- Keep backups of my files.
- Secure my GitHub account.

# 2. Identification
- Look for suspicious changes.
- Check for leaked passwords or private information.

# 3. Containment
- Secure the affected account.
- Limit access to affected files.

# 4. Recovery
- Restore deleted or changed files.
- Change exposed passwords.

# 5. Lessons Learned
- Write down what happened.
- Find ways to prevent it from happening again.

# Purpose
This runbook explains how I would respond to security problems involving my cybersecurity challenge log and GitHub repository.
